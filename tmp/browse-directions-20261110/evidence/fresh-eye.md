老板，Shelf 当前已经实现“打开详情 → 选版本 → 确认”，也有退出动画、阅读区交叉淡入淡出和减少动态效果分支。接下来优先修键盘阅读与返回焦点，再处理切换动画。

已检查两张基线联系表：`evidence/shelf-motion-wide.png`、`evidence/shelf-motion-390.png`。**它们早于当前源码**；旧报告里的状态突然出现、海报悬浮位移等问题，不能直接当成当前缺陷。审查期间源码又更新过，最后读取已包含比较列表快照和撤销按钮按当前作品限定，以下不再报告这两项旧问题。

按严重程度排序：

1. **P1 · Interaction / accessibility：键盘无法可靠滚动简介。**
   `src.tsx:140` 的阅读滚动区没有 `tabIndex`，内部也没有可聚焦控件；实际焦点在外部工具栏或固定底栏。长简介出现后，键盘用户没有可靠入口把滚动操作交给正文。滚动定义见 `study.css:231`。
   **建议：**给当前阅读区可聚焦入口和可访问名称，显示焦点轮廓，让 PageDown、方向键能够滚动正文；保留现有关闭入口。

2. **P1 · Interaction：追番后关闭，可能无法恢复书架焦点。**
   开启“未追番”筛选，打开一部作品并确认追番，会使原海报从 `filtered` 中移除（`src.tsx:170`）。关闭时只对保存的旧元素调用 `.focus()`（`src.tsx:186`），没有检查它是否仍连接到文档。比较列表快照已经保住详情内的前后切换，但尚未解决返回焦点。
   **建议：**关闭时先检查原入口是否存在；否则聚焦原位置附近的可见海报，空结果时聚焦筛选或搜索，同时保留滚动位置。

3. **P2 · Polish / motion：滚动后切换作品，退出层会从正文顶部重新出现。**
   `src.tsx:139` 新建一个 outgoing 滚动容器，只复制作品数据，没有复制当前正文的 `scrollTop`；原 current 又在 `src.tsx:140` 因作品 key 改变而卸载。因此读到简介下方再切换，淡出的旧作品会重新从顶部绘制，破坏阅读连续性。
   **建议：**保留实际的旧阅读节点直到退出完成，或为退出层复制滚动位置；新作品从顶部进入即可。这个问题来自当前源码，旧影片没有验证该操作路径。

4. **P2 · Hierarchy：长简介滚动时，海报和标题也会消失。**
   `study.css:231` 把海报、标题、简介一起放在滚动容器内，与 `INTENT.md:33` 要求的“阅读时保留海报和标题”不符。390px 基线第一行第二格展示了紧凑详情，但静态格子不能证明滚动后的身份信息仍然可见。
   **建议：**在现有详情面板内保留紧凑的作品身份栏，让简介独立滚动；继续使用当前固定底栏，无需增加页面或步骤。

5. **P2 · Interaction / accessibility：星期筛选声明为 tabs，却没有对应键盘操作。**
   `src.tsx:288` 的 `tablist` / `tab` 只有点击处理，没有方向键切换或 roving `tabIndex`。用户必须逐个 Tab 穿过八个选项，辅助技术得到的控件语义也与操作方式不一致。
   **建议：**这里本质上是过滤器，可改为带 `aria-pressed` 的按钮组；若保留 tabs，则补齐方向键、Home/End 和单一 Tab 入口。

6. **P2 · Framing：窄屏固定介绍区挤压真正找番的空间。**
   390px 基线第一行第一格中，海报出现前依次经过产品顶栏、英文季节标签、标题、说明、搜索、星期和数量行。当前仍保留这套布局（`src.tsx:338`；`study.css:366`），且只有海报网格滚动（`study.css:94`），介绍区会持续占用高度。
   **建议：**紧凑布局隐藏英文标签和说明，缩小标题、搜索之间的间距，保留搜索与星期筛选，让更多海报进入首屏。

7. **P2 · Hierarchy / accessibility：辅助文字过淡、字号偏小。**
   当前仍使用白底上的 `#969da6` 说明文字、`#9ca3ad` 搜索占位符，以及 9px 的数量和海报元信息（`study.css:74`、`study.css:79`、`study.css:92`、`study.css:103`）。两张基线首页格子也能看到这些信息明显弱于正文。
   **建议：**先提高搜索、数量、星期等找番信息的对比度；紧凑布局的必要信息至少采用现有 12px 正文级别，并实际测量对比度。

**验证边界：**本次只读源码、意图文档、两张联系表及对应 JSON，并为确认控件语义少量读取 kit。没有编辑、启动浏览器、运行构建、执行 git 或使用子代理。未实测当前版本的动画帧率、快速连续切换、屏幕阅读器、缩放和触屏；两个旧 JSON 都标为 `inconclusive` 且存在采样间隙，因此不能据此宣称当前动画已通过验收。范围仅限 Shelf。
