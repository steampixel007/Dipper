## Changelog

- Redesign release selection around viewing preferences: choose subtitle language, quality, compatibility, or storage priority, and get a recommended version automatically.
- Default to the subtitle group with the most available releases, with each group's resource count shown.
- Select one release per episode by default, prefer later revisions such as `01v2`, and allow switching to another version for any episode.
- Add an original-title fallback that shows the source title, explains recognized terms, and lets users include or exclude words with a live preview.
- Recognize `SxxExx` episode numbers, `EP01~EP10` collections, and equivalent E-AC3/DDP audio labels across release titles.
- Add Windows minimize, maximize/restore, and close controls.

## 更新日志

- 重新设计资源选择：按字幕语言、画质、兼容性或省空间偏好推荐版本，并自动选中更合适的一份。
- 字幕组默认选择历史资源最多的一组，并显示该组可用的资源数量。
- 每集默认只选一份资源，优先选择 `01v2` 等修订版，也可以为单集切换其他版本。
- 新增按原标题追番的兜底方式：显示原始标题、解释识别到的词，并支持包含/排除关键词和实时预览。
- 支持识别 `SxxExx` 集数、`EP01~EP10` 等合集，以及 E-AC3/DDP 等不同写法的音频标签。
- 增加 Windows 窗口的最小化、最大化/还原和关闭按钮。
