## Changelog

- Read anime synopses in a side panel while browsing the catalog. Reopening an anime reuses its loaded synopsis.
- Fix an RSS error where a canceled request could be reported as a truncated response.
- Update the MyGo desktop toolkit and BitTorrent library.
